## 🔍 Overview

**BaqBayt Homes** is a professional landing page covering the company's three core focus areas:

| # | Sector | Description |
|---|--------|-------------|
| 1 | 🧭 **Surveying** | Land and property surveying services |
| 2 | 🏠 **Real Estate** | Property listings and housing solutions |
| 3 | 💼 **Business** | Corporate and commercial offerings |

## ✨ Features

| Feature | Description |

## 🛠️ Setup & Usage

### 1. Clone the repository

```bash
git clone https://github.com/SireTallest/BaqBayt-Homes.git
```

### 2. Navigate into the project folder

```bash
cd BaqBayt-Homes
```

### 3. Open in your browser

```bash
# Simply open the file directly — no build tools or installs needed
open index.html
```

> 💡 **Note for Windows users:** You can double-click `index.html` or right-click → *Open with* → your preferred browser.
