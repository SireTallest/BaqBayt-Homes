# 🏡 BaqBaytHomes – Landing Page

A responsive, multi-page landing website built with **Semantic HTML5, CSS3, and Vanilla JavaScript** for **BaqBayt Homes**.  
This project covers the company’s three major focus areas:

1. **Surveying Aspects** 🧭  
2. **Real Estate** 🏠  
3. **Businesses** 💼  

---

## ✨ Features

- 🎨 **Modern & Clean UI** with semantic HTML and custom CSS (no frameworks).  
- 📱 **Fully Responsive Design** (mobile, tablet, desktop friendly).  
- 🧭 **Navigation Menu** linking to Home, Surveying, Real Estate, and Business pages.  
- 🎠 **Interactive Carousel** with arrow controls and hover effects.  
- 🖱️ **Hover Animations & Transitions** for professional and fun user experience.  
- 📂 **Multi-page Structure** (index, surveying, business, etc.).  
- 🔒 **Scalable Codebase** for future functionality integration.

---

## 🚀 Technologies Used

- **HTML5** → Semantic structure  
- **CSS3** → Custom variables, grid, flexbox, transitions  
- **JavaScript (Vanilla)** → Carousel scrolling, responsive menu toggle
